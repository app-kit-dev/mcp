# App-Kit MCP

[![MCP](https://img.shields.io/badge/MCP-Streamable%20HTTP-0a7cff)](https://modelcontextprotocol.io)
[![Endpoint](https://img.shields.io/badge/endpoint-mcp.app--kit.dev-222)](https://mcp.app-kit.dev/mcp)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue)](LICENSE)

Удалённый MCP-сервер, который даёт ИИ-агенту SEO-аудит сайта, проверку текста (читаемость, «вода»,
стоп-фразы, грамматика), PDF в картинки и картинки в PDF, конвертацию форматов. Подключается
одной строкой к Claude, Cursor, VS Code, Windsurf. Бесплатно и без регистрации - в пределах лимитов.

```
https://mcp.app-kit.dev/mcp
```

[English](README.md) | [Описание tools](docs/tools.md) | [app-kit.dev](https://app-kit.dev/mcp)

Здесь - документация, готовые конфиги клиентов и метаданные для каталогов MCP. Сам сервер работает
как сервис App-Kit, ставить ничего не нужно.

## Зачем

Попросить агента «проверь SEO у сайта и скажи, что чинить первым» или «вычитай текст лендинга»
и получить ответ на цифрах, а не на догадках модели:

- **SEO-аудит** - оценка 0-100 по группам, проваленные проверки, пять самых дорогих потерь.
  Движок знает 400 проверок: техническое SEO, скорость, разметка, готовность к ИИ-поиску и др.
  Быстрый режим - до 10 страниц примерно за минуту.
- **Проверка текста** на русском и английском, до 20 000 символов: метрики «воды», заспамленности
  и тошноты, читаемость, стоп-фразы, грамматика. Сервер возвращает координаты замечаний, а не куски
  вашего текста.
- **Картинки и PDF** - страницы PDF в PNG/JPEG/WebP, картинки в PDF, конвертация форматов
  (сжатие в WebP/AVIF - скоро). Файл передаётся ссылкой или через одноразовый адрес загрузки, без мегабайтов
  base64 в чате.

## Подключение

Без токена всё работает анонимно. Чтобы поднять лимиты, возьмите бесплатный токен на
[app-kit.dev/mcp](https://app-kit.dev/mcp) (одна кнопка, без email). Токен передаётся заголовком
`Authorization: Bearer mcpf_...` или прямо в адресе: `https://mcp.app-kit.dev/mcp/t/mcpf_...`.

**Claude Code**

```bash
claude mcp add --transport http app-kit https://mcp.app-kit.dev/mcp
# с токеном:
claude mcp add --transport http app-kit https://mcp.app-kit.dev/mcp \
  --header "Authorization: Bearer mcpf_ваш_токен"
```

`--scope user` - чтобы сервер был виден во всех проектах.

**Claude.ai и Claude Desktop.** Customize > Connectors > **+** > **Add custom connector**, адрес -
`https://mcp.app-kit.dev/mcp/t/mcpf_ваш_токен`, вход - без авторизации. Токен в адресе здесь
почти обязателен: claude.ai ходит к серверам с общих IP Anthropic, и анонимный лимит у всех его
пользователей один на всех. На бесплатном тарифе Claude можно подключить один свой коннектор.
Подробно - [examples/claude-desktop/claude.ai.md](examples/claude-desktop/claude.ai.md).

**Cursor** - `.cursor/mcp.json` в проекте или `~/.cursor/mcp.json`: [пример](examples/cursor-mcp.json).

**VS Code** - `.vscode/mcp.json`, токен VS Code спросит один раз: [пример](examples/vscode-mcp.json).

**Windsurf (Devin Desktop)** - в `mcp_config.json` сервер задаётся ключом `serverUrl`, заголовки
поддерживают `${env:ИМЯ}`; пример - в [README](README.md#windsurf-devin-desktop).

Любой другой клиент с удалённым MCP (Streamable HTTP): адрес `https://mcp.app-kit.dev/mcp`
и, при желании, заголовок с токеном.

## Инструменты

| Tool | Что делает | Как попросить |
|---|---|---|
| `seo_audit_fast` | Быстрый аудит корня сайта; ждёт до 60 с, дальше отдаёт `handle` | «Проверь SEO у example.ru, что исправить в первую очередь?» |
| `seo_audit_status` | Результат аудита по `handle` | модель вызывает сама |
| `text_check` | Метрики, читаемость, стоп-фразы, грамматика | «Проверь текст на воду и ошибки: ...» |
| `quota_status` | Уровень доступа и остатки лимитов | «Сколько бесплатных проверок App-Kit у меня осталось?» |
| `image_convert` | PNG, JPEG, WebP, BMP, TIFF, GIF | «Переведи логотип в PNG: ...» |
| `pdf_to_images` | Страницы PDF в картинки, до 20 страниц | «Сделай PNG из первых трёх страниц этого PDF» |
| `images_to_pdf` | Собрать до 20 картинок в один PDF | «Сделай PDF из этих трёх скриншотов: ...» |
| `conversion_status` | Результат долгой конвертации по `handle` | модель вызывает сама |
| `create_upload` | Одноразовая ссылка для загрузки локального файла | «Сделай PNG из ./scan.pdf» |
| `image_compress` *(скоро)* | Сжатие в WebP/AVIF, ресайз | «Сожми https://example.ru/hero.png в AVIF» |

Схемы входа и выхода - [docs/tools.md](docs/tools.md). Все инструменты только читают: ничего
не публикуют и не меняют. Готовые файлы отдаются ссылкой на 10 минут и маленьким превью.

## Лимиты

| Tool | Анонимно | С токеном | Примечание |
|---|---|---|---|
| `text_check` | 10 в час | 20 в час | |
| `seo_audit_fast` | 5 в час | 10 в час | один домен - не больше 20 аудитов в сутки от всех |
| `seo_audit_status`, `conversion_status`, `quota_status` | бесплатно | бесплатно | квоту не тратят |
| `image_convert` | 5 в час | 20 в час | |
| `pdf_to_images`, `images_to_pdf` | 3 в час | 10 в час | до 20 страниц / файлов, 20 МБ |
| `create_upload` | 10 в час | 30 в час | до 20 МБ, ссылка живёт 10 минут |

Остаток приходит в каждом ответе (`quota`) и по `quota_status`. У бесплатного слоя есть и общий
суточный бюджет на инструмент - когда он кончается, инструмент так и пишет; сброс в 00:00 UTC.

## Цены

Бесплатный слой остаётся бесплатным. Больше лимитов, полный многостраничный SEO-аудит с PDF-отчётом
и крупные файлы - в платном App-Kit API, оплата кредитами App-Kit. Подробности - на
[app-kit.dev](https://app-kit.dev).

## Данные

- Сервер находится в Германии.
- Текст для `text_check` не сохраняется - возвращаются только метрики.
- Файлы живут только на время обработки и удаляются не позже чем через 15 минут.
- IP нужен только для анонимных лимитов и хранится как хэш с солью не дольше 24 часов.
- В журнале - имя инструмента, время и статус; без IP, текстов, файлов и полных URL.
- Содержимое проверяемых страниц не пересказывается дословно: только оценки, коды проверок и
  короткие обрезанные поля с пометкой «данные со страницы».

Политика целиком - на [app-kit.dev/mcp](https://app-kit.dev/mcp).

## Вопросы

**Нужна регистрация?** Нет. Токен бесплатный и без email, он только поднимает лимиты.

**Можно проверить тестовый стенд?** Только сайт, открытый из интернета. Локальные и внутренние адреса,
нестандартные порты отклоняются.

**Аудит вернул `status: running`.** Модель сама вызовет `seo_audit_status` через `poll_after_s`
секунд. `handle` действует 60 минут и только для того, кто запустил аудит.

**Код сервера открыт?** Нет, это сервис. Открыты (MIT) документация, примеры и метаданные в этой репе.

**Куда писать?** Ошибки и пожелания - в [issues](../../issues), уязвимости - по [SECURITY.md](SECURITY.md).
