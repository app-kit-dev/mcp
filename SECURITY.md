# Security policy

Please report vulnerabilities privately to **hello@app-kit.dev** with "Security: App-Kit MCP" in
the subject. Do not open a public issue for security problems.

Include what you found, how to reproduce it and the impact you expect. We reply within 3 business
days and keep you updated until the issue is fixed.

In scope: the hosted server `mcp.app-kit.dev` (authentication, rate limits, handles and download
links, server-side URL fetching, data handling) and the content of this repository.

Please do not run load tests, scan third-party sites through the audit tool or access data that is
not yours. Good-faith research within these rules is welcome.
